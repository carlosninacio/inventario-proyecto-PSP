# 🧾 Sistema de Inventarios para Minimercado

Un **portal web de inventario** desarrollado para facilitar la gestión de productos en un minimercado.  
El sistema permite **registrar, visualizar, editar y eliminar** artículos desde una interfaz web conectada a una base de datos.

---

## 🚀 Descripción del proyecto

Este proyecto va a ser desarrollado como parte de la materia **Proceso Personal de Software**.  
El objetivo es crear un **sistema web sencillo y funcional** que permita al administrador de un minimercado mantener un control actualizado del inventario.

El portal va a incluir:

- Una **tabla dinámica** que muestra los productos almacenados en la base de datos.  
- Un **formulario** para agregar nuevos productos.  
- Opciones integradas en la tabla para **editar o eliminar** productos.  
- Conexión directa con la base de datos para garantizar persistencia de la información.

---

## 🧩 Características principales

- Interfaz intuitiva y fácil de usar.  
- Operaciones **CRUD completas** (Crear, Leer, Actualizar, Eliminar).  
- Base de datos conectada al backend para registrar los cambios.  
- Código estructurado para facilitar mantenimiento y mejoras futuras.

---

## 🏗️ Arquitectura del sistema

El sistema se basa en una arquitectura **cliente-servidor**, compuesta por:

- **Frontend:** Angular (HTML, TypeScript, Estilos Bootstrap).  
- **Backend:** Java con Spring Boot (gestión de lógica y endpoints).  
- **Base de datos:** MySQL (almacenamiento de los productos).
